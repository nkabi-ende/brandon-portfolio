# Brandon TJ Nkabinde product portfolio

Static site source is in `dist/`. The HTML contains the case studies and source links. Interactions are in `dist/assets/site.js`, with native links and readable case studies available without JavaScript.

The optional desktop smooth scrolling uses the MIT-licensed Lenis v1.3.27 source from Darkroom Engineering. The browser modules and license are vendored under `dist/assets/vendor/lenis-1.3.27`.
